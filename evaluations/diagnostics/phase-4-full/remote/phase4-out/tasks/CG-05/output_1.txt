Here's a TypeScript validator for a user profile using **Zod**, a powerful schema validation library. This implementation includes:

- Required fields: `id` (string), `email` (string containing `@`)
- Optional field: `displayName` (string)
- Useful error messages
- Passing and failing examples

---

### ✅ Implementation with Zod

```ts
import { z } from 'zod';

// Define the schema
const userProfileSchema = z.object({
  id: z.string().min(1, "ID is required"),
  email: z.string().email("Email must contain '@' and be a valid email address"),
  displayName: z.string().optional(),
});

// Validator function
function validateUserProfile(data: unknown): { success: boolean; errors: string[] } {
  const result = userProfileSchema.safeParse(data);
  if (result.success) {
    return { success: true, errors: [] };
  } else {
    return {
      success: false,
      errors: result.error.format(),
    };
  }
}
```

---

### 📌 Example Usage

#### ✅ Passing Example

```ts
const validData = {
  id: "12345",
  email: "user@example.com",
  displayName: "John Doe",
};

const result = validateUserProfile(validData);
console.log(result); // { success: true, errors: [] }
```

#### ❌ Failing Example 1: Missing `id`

```ts
const invalidData1 = {
  email: "user@example.com",
  displayName: "John Doe",
};

const result1 = validateUserProfile(invalidData1);
console.log(result1); // { success: false, errors: ["ID is required"] }
```

#### ❌ Failing Example 2: Invalid `email`

```ts
const invalidData2 = {
  id: "12345",
  email: "user.com", // missing '@'
  displayName: "John Doe",
};

const result2 = validateUserProfile(invalidData2);
console.log(result2); // { success: false, errors: ["Email must contain '@' and be a valid email address"] }
```

#### ❌ Failing Example 3: Invalid `email` format

```ts
const invalidData3 = {
  id: "12345",
  email: "user@.com", // invalid email format
  displayName: "John Doe",
};

const result3 = validateUserProfile(invalidData3);
console.log(result3); // { success: false, errors: ["Email must contain '@' and be a valid email address"] }
```

---

### 📌 Notes

- This implementation uses **Zod** for schema validation.
- The `email` field uses Zod's built-in `email()` validator, which ensures the string contains `@` and follows standard email format.
- The `displayName` field is optional and not validated beyond being a string.
- Error messages are generated by Zod's `format()` method, which provides detailed error messages for each field.
