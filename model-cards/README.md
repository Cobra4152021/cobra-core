# Model Cards / Manifests

Store `ModelManifest` JSON records for evaluation targets.

- Do **not** commit model weights.
- Do **not** commit API keys or private tokens.
- Qwen is the first planned evaluation target; Mistral, Gemma, and others must fit the same schema.
- `EXAMPLE_qwen_manifest.json` is a structural example only (`model_revision: not-acquired`).
