# Citation Provenance

Request-local alias `EV-001` maps to:

- `connector_id`
- `vault_source_id`
- `vault_document_id`
- `source_version`
- chunk/excerpt location
- `integrity_hash`
- retrieval timestamp
- display title

Provider output may only cite retrieved aliases. Unknown/denied/integrity-failed citations → `invalid_evidence_citation`.
