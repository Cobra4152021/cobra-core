# Error Model

```json
{
  "error_code": "validation_error",
  "message": "limit must be an integer",
  "request_id": "…",
  "timestamp": 0.0,
  "documentation_url": "https://docs.cobra.local/api/errors/validation_error"
}
```

Codes include: `unauthenticated`, `forbidden`, `not_found`, `validation_error`, `rate_limited`, `conflict`, `internal_error`, `version_unsupported`, `bad_request`.
