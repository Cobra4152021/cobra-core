# Versioning Policy — @cobra-core/knowledge-engine

Aligned with Worker `docs/KC011_VERSIONING.md`.

## Semver
- **MAJOR** — breaking TypeScript/API/data contracts
- **MINOR** — backward-compatible packs/features
- **PATCH** — fixes and hardening only

## v1.0 freeze
Investigator, Government, Labor, Research, Studio, Marketplace SDK, and Enterprise public modules are frozen against breaking changes in 1.x.

## Compatibility
Consumer Worker 1.0.x requires core 1.0.x. See Worker `docs/KC011_COMPATIBILITY_MATRIX.md`.
