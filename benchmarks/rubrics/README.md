# CobraBench Rubrics

Weighted scoring and category rubrics for CobraBench.

## Initial weights (`cobrabench_v1_weights.json`)

| Category | Weight |
| --- | ---: |
| Investigation reasoning | 20% |
| Evidence grounding | 15% |
| Hallucination resistance | 15% |
| Citation correctness | 15% |
| Contradiction detection | 10% |
| Coding | 10% |
| Long-document analysis | 5% |
| Refusal quality | 5% |
| Instruction following | 5% |

Overall scores are derived summaries. Category cells remain the authoritative detail.
