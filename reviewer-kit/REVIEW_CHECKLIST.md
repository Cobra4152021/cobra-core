# Reviewer Checklist

## Before starting

- [ ] Read `README.md` and `OVERVIEW.md`
- [ ] Confirm which release directory you are reviewing (usually `cobrabench-v0.2-rc2`)
- [ ] Confirm you will **not** load models or run protocols
- [ ] Record independence limitations honestly

## Per case — blind

- [ ] Prompt + evidence only
- [ ] Answerability recorded
- [ ] Ambiguity / missing evidence recorded
- [ ] Plausible conclusions recorded
- [ ] Blind form saved

## Per case — after rubric reveal

- [ ] Expected behaviors challenged for alternatives
- [ ] Prohibited behaviors checked for overbreadth
- [ ] Evidence IDs validated against sources
- [ ] Semantic vs exact-format requirements clear
- [ ] Evaluator assignment sensible
- [ ] Output budget realistic
- [ ] Difficulty rating checked
- [ ] Defect severity assigned (D0–D4)
- [ ] Approval status assigned

## Suite-level

- [ ] Category balance concerns noted (if any)
- [ ] Small-sample categories noted (refusal, uncertainty)
- [ ] Evaluator limitation warnings acknowledged
- [ ] Contamination / answer-cue scan notes
- [ ] Summary report completed with Outcome A/B/C/D
